# Transcript bank

## IDs
- `S1–S15`: personal-data subtypes
- `C1–C4`: advice contexts
- `I1–I15`: interaction turns
- `G1–G4`: counterbalancing groups

| ID | Subtype |
|---|---|

| S11 | Financial account |
| S12 | Transactions |
| S13 | Diagnoses |
| S14 | Genetic data |
| S15 | Personal health history / medication experiences |

Contexts: `C1` Health & wellness; `C2` Professional & career; `C3` Relationships; `C4` Personal finance.

## Rotation
Each participant sees all 15 subtypes once. Context rotates across four groups. Across G1–G4, each subtype appears once in every context.

## Memory rule
Within one participant, I1–I15 use S1–S15, so all 15 memory updates are different. Across counterbalancing groups, the memory for a given subtype stays the same while the context rotates.
